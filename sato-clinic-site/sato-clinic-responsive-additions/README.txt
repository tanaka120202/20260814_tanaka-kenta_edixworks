佐藤医院 レスポンシブ対応の追加ファイル

既存のHTML・style.cssは、このZIPには入れていません。
変更済みの文章・PCデザインを上書きせず、以下の追加だけで導入します。

1. ファイルを追加
   css/responsive.cssを、現在のサイトのcssフォルダーにコピーします。
   assets/hospital-mobile.pngを、現在のサイトのassetsフォルダーにコピーします。
   同名のファイルがすでにある場合は、先に別名で保存してください。

2. 全ページの<head>内に1行追加
   既存のstyle.cssの読み込みより後に、head-addition.htmlの1行を追加します。

   <link rel="stylesheet" href="./css/style.css">
   <link rel="stylesheet" href="./css/responsive.css">

   既存のviewport設定も残してください。
   <meta name="viewport" content="width=device-width, initial-scale=1">

3. 全ページの<body>の開始タグ直後に追加
   body-addition.htmlのdivをコピーします。
   固定背景は、このdivだけにopacity: .15を指定しています。
   文字・写真・ボタンの濃さには影響しません。

4. 全ページの<header class="site-header">の内側に追加
   header-addition.htmlのdetails要素全体をコピーします。
   既存のPC用ナビゲーション、ロゴ、キャッチコピーは削除しません。
   右上の三本線をクリックすると、緑のメニューが開きます。
   再度クリックすると閉じます。キーボードのEnter/Spaceでも開閉します。
   メニューのリンク先を変更している場合は、hrefを現在のファイル名に合わせてください。

補足
- 同梱のHTMLファイルは挿入用の断片です。独立したページとして使うものではありません。
- JavaScriptは使用していません。メニューは標準HTMLのdetails/summaryを使用します。
- 402pxを基準にし、320px〜1439pxにも幅を調整する設定を追加しています。
- 1440px以上では既存のPC用スタイルをそのまま使用します。
- 1023px以下では、スマホ用ヘッダー・メニュー・固定背景を表示します。
- hospital-mobile.pngは、添付ZIPの「hospital_5 2.png」を名前だけ変更したものです。
- 各ページで同じ背景ファイルと表示位置を指定するため、ページ移動後も背景の配置は同じです。
- 対応するクラス名は、先ほど作成したHTMLのクラス名です。
  クラス名やHTMLの親子構造も変更した場合、その箇所のCSSセレクターを合わせてください。
  文章だけの変更では、原則として調整は不要です。
- 本文は長さに合わせて伸びるようにしており、変更済みの文章を置き換えません。
- 検索除外設定と、学習用サイトの断り書きは、現在のHTMLにそのまま残してください。
- お知らせの件数、日付、パンくず等の掲載内容は追加・変更していません。

確認
スマホの表示幅で横スクロールがないこと、三本線メニューが開閉すること、
スクロールしても背景の位置が動かないことを確認してください。
既存のサイトを直接編集する前に、現在のフォルダーをコピーしておくと元に戻せます。
